# Synthetic demo data

`student_records_synthetic.csv` is a 4,000-record dataset generated with Python's Faker library for this portfolio project. All person-like details are fictional and included to support full ERP demonstrations: roll-number lookup, topper details, club membership, and student performance analysis.

The file is safe to use for testing and practice. Never commit a real institution's student export, even if it has the same schema.
